## เหตุผลและข้อควรระวัง
- Prisma Schema กำหนด `party.name @unique` ขณะที่ Error Handler แปลง Prisma P2002 เป็น HTTP 409 จึงสามารถใช้ Test Double ทดสอบการจัดการข้อมูลซ้ำได้
- เอกสารไม่ได้กำหนดความยาวสูงสุดของชื่อหรือนโยบาย จึงไม่เพิ่มค่าขีดจำกัดขึ้นมาเอง
- ห้ามนำ Token, Password และข้อมูลบัญชีจริงมาเป็น Test Data หรือใส่ในรายงาน
- ต้องปรับปรุงสถานะและอ้างอิงไฟล์ทดสอบเมื่อเขียนและรัน Test ครบแล้ว
